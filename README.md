# sonora-radio

A Sonora Multiroom hub extension (planned) that plays internet radio from the
[radio-browser.info](https://www.radio-browser.info/) catalogue: search stations through the hub and
play one on any output or group by its station UUID.

Status: design only. See [docs/backlog/INDEX.md](docs/backlog/INDEX.md) and [AGENTS.md](AGENTS.md).
